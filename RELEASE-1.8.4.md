# Web Debug 1.8.4 — coherent visual direction

Short briefs need a concrete visual direction, not only a requirement to avoid dated UI. This patch refines the existing design workflow with a conditionally loaded guide for choosing a focal subject, relating it to typography and page structure, adapting components into one visual system, and making motion explain a state change.

A dated reference map adds GetLayers, React Bits Pro, Aceternity UI and Magic UI. Observed public previews, source descriptions and verification limits are distinguished. Four explicit HTTPS source entries support later review; they do not install libraries, connect services or authorize access to paid code/prompts.

The guide includes resource-aware rendering, pause/reduced-motion behavior, deliberate fallback and separate visual/functional critique. The modern-by-default and expanded-option requirements remain intact. Existing project facts, stack, user style choices and scope remain authoritative.

An original local visual-material studio walkthrough exercises these decisions with connected shape/material controls, local saved studies and a static fallback. It is developer-authored evidence, not a cross-model performance result. The prototype, font and browser artifacts are excluded from skill packages.

The only executable core change is VERSION; no new runtime dependency or remote-control endpoint is introduced. This remains a signed 1.8.x patch for unchanged enrolled local clients. Cowork account ZIP replacement remains manual. See [validation](VALIDATION-1.8.4.md).
