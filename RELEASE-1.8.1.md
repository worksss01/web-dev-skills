# Web Debug 1.8.1 — design craft and continuity

This patch refines the existing short-brief design workflow. A focused craft reference covers relationships across a page, task-specific information density, useful control feedback, interrupted/reversed states and narrow-screen representations that preserve selected context and data. It is loaded for substantial creation/redesign, not every small fix.

Eight selected reference mechanisms extend the earlier visual vocabulary with page narratives, explanatory motion, a timeline selector, a planner and operational interfaces. Dated observations and limitations stay distinct from source claims. Bulk research, third-party screenshots and demo assets are not installed with the skill.

UI diagnosis now explicitly checks outcomes after input, meaningful readiness and continuity when representations change. Maintainer design cases add planner continuity and a product-control story. Core/Cowork helpers remain identical; the only core executable change is the release version. No new runtime dependency, cloud account, telemetry, network listener or permission is added.

This is an eligible patch for unchanged managed 1.8.x installations under their existing policy. Local edits still block replacement. Cowork account ZIP replacement remains manual. See [validation](VALIDATION-1.8.1.md) and [managed updates](docs/UPDATES.md).
