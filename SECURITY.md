# Security reports

Use [GitHub private vulnerability reporting](https://github.com/worksss01/web-dev-skills/security/advisories/new). This channel is enabled for this repository. Do not open a public issue containing exploit details, credentials, private code, personal information or unsanitized logs.

Include the affected Web Debug version, relevant helper/instruction, impact and a minimal synthetic reproduction. Distinguish observations from suspected root cause. Omit credentials even from private reports. If private reporting is unavailable, open an issue requesting a private contact without vulnerability details.

We can patch our own code and guidance; we cannot claim to repair a provider's service. There is no guaranteed response time or bug bounty. The current release is maintained; older versioned reports are historical evidence, not a promise of support for every past version.
