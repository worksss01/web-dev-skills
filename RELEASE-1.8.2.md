# Web Debug 1.8.2 — expanded option surfaces

A styled closed form control can still open an unstyled browser/OS option list. The prior planner walkthrough missed that expanded visual state. This patch makes open selects, comboboxes and related pickers explicit review targets, including their relationship to the trigger and their behavior within narrow or scrolling dialogs.

Guidance preserves the choice of suitable native or existing project components. A custom surface must retain form values, keyboard navigation, commit/cancel behavior, useful focus and honest compatibility limits. The maintainer evaluation set adds an option-surface case. Current primary references are linked without copying their example implementations into the skill.

The local planner study now uses original themed day/work-type choices with keyboard and pointer interaction. That study and its browser captures remain local; the distributed change is guidance and versioned validation. The only executable helper change is VERSION. No dependency, permission, telemetry or network listener is added.

This is a signed patch for unchanged enrolled 1.8.x installations under their existing policy. Cowork account ZIP replacement remains manual. See [validation](VALIDATION-1.8.2.md).
